# 01 — กติกา Colosseum (ถอดจาก FAQ ทางการ)

> ที่มา: https://colosseum.com/hackathon — ดึง 23 ก.ย. 2026

## คุณสมบัติ

- เปิดทุกประเทศ ทุกเชน — submission ไหนก็ลุ้นรางวัลรวมได้
- งานนี้แข่ง **startup ใหม่** ไม่ใช่บริษัทที่ระดมทุนไปเยอะแล้วหรือทำโปรดักต์เดิมมาหลายปี
- เริ่ม dev มาก่อนได้ แต่**กรรมการตัดสินเฉพาะงานที่ทำในช่วงแข่ง (14 ก.ย. – 12 ต.ค.)**
- ใช้ pre-existing code ได้ แต่**ต้องเปิดเผยในฟอร์มส่งงาน** ไม่งั้นโดนตัดสิทธิ์/แบน/ริบรางวัล
- โค้ด open-source ของคนอื่นใช้ได้ตามปกติ (สนับสนุนให้ compose กับ protocol ที่มีอยู่)

## กติกาทีม

- **1 คน = 1 โปรเจกต์ = 1 ทีมเท่านั้น** ห้ามส่งหลายงาน
- ส่งเดี่ยว (solo founder) ได้ แต่แนะนำให้หาทีม
- ทุกคนในทีมต้องสมัคร Colosseum account; หัวหน้าทีมเป็นคนกด submit

## ของที่ต้องส่ง (submission portal)

1. ชื่อโปรดักต์ + คำอธิบายสั้น
2. ใช้เชน/เครื่องมืออะไรบ้าง
3. สมาชิกทีม + ประวัติแต่ละคน
4. ทีมอยู่ที่ไหน
5. โลโก้/กราฟิก
6. ลิงก์ GitHub (public แนะนำ; private ได้แต่ต้องให้สิทธิ์ hackathon@colosseum.com)
7. **วิดีโอ pitch 2–3 นาที** (กรรมการดูอันนี้ก่อน — ต้องชัด กระชับ)
8. **วิดีโอ demo ผลิตภัณฑ์ ≤3 นาที**
9. GTM: กลยุทธ์ตลาด การ验证需求 แผน distribution

แถม: weekly update คลิปละ 1 นาที (ไม่บังคับ แต่ทีมที่เอาจริงควรทำ)

## เกณฑ์ตัดสิน (7 ข้อ)

1. Founder + Market Fit — ทีมเหมาะกับตลาดนี้ไหม ทำไมถึงอิน
2. Insight — มี insight เฉพาะตัวจากความเข้าใจปัญหาลึกไหม
3. Product + Execution — ของใช้งานได้ดีแค่ไหน เทียบคู่แข่ง ชิปเร็วไหม
4. Potential Market Size — ตลาดใหญ่/โตเร็วแค่ไหน
5. Founder Communication — เล่าเรื่องชัด ขยาย user base ได้ไหม
6. Viability — เป็นธุรกิจ scale ได้จริงไหม
7. Traction — มี demand/revenue แล้วหรือยัง

กระบวนการ: ทีม Colosseum รีวิวทุกงาน → shortlist → กรรมการให้คะแนน → ทีมเต็งโดนเรียก **Zoom 15 นาที** → ประกาศผู้ชนะ

## เรื่องต้องรู้อื่น ๆ

- ไม่ต้องเป็นสายเทคนิคก็แข่งได้ (เคยมี non-technical founder สร้าง MVP ด้วย AI coding tools แล้วได้เข้า accelerator)
- ชนะแล้ว**ไม่บังคับ**เข้า accelerator
- Code of conduct: ห้าม harassment ดูถูก เหยียด — ฝ่าฝืนโดนตัดสิทธิ์
- ฟีดแบ็กรายทีมไม่มี (งานส่งเยอะ) แต่รับประกันว่าทุกงานมีคนรีวิว
- อีเวนต์ onsite: Colosseum office ที่ SF + Superteam/Solana Foundation จัด build space ตามเมืองต่าง ๆ (กทม. มี — ดูไฟล์ 03)
